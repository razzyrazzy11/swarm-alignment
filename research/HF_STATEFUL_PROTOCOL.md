## Question and matched evidence

Does a separately served Llama model family exhibit the same supported-decision and evidence-restoration pattern on the same packets? Use meta-llama/Llama-3.3-70B-Instruct through the explicitly pinned Novita HF route. It is a matched model-family/serving comparison, not an independent source-scenario sample or evidence that two services serve identical weights. Requested/returned model strings are retained; the returned-model allowlist permits the catalog spelling and two punctuation/case spellings of that same selected model; an unexpected identity halts the run. A public model name is not an immutable checkpoint hash.

Select source indices 0–7 from each of the three main-v2 families: 24 source draws, four clean/four scripted violations per family. Derive them from the registered seed function, never from model outputs. Use all ten main-v2 evidence views for each: both naming conditions, full/random/selective exports and priority/random two-record authentic restoration for selective views. Total **240 calls**. Approval-join outputs are not used for prompt/rule development or training. Earlier partial Qwen outputs remain evaluation data; no Llama response has been observed at v3 registration and neither prompt nor subset was tuned from Qwen accuracy.

Use the exact registered main-v2 PROMPT, public packet bytes, label checker and predeclared encoding parser. Fresh system/user messages, temperature zero, 4,096 output tokens, no tools or cross-call memory. HF Chat Completions is a different transport; only a terminal stop choice with string content normalizes to completed. No transport failure is turned into a refusal or justified abstention. The allowed JSON envelope, unsupported worker/NONE findings and raw strict validity have the same meanings as in the Adaption core.

## Pricing, limits and freeze

The [HF routing contract](https://huggingface.co/docs/inference-providers/en/index) supports explicit provider suffixes and a live model catalog. Recheck the selected live provider's price before dispatch: frozen input **$0.135/M** and output **$0.40/M** tokens. Stop if that catalog price or provider availability differs; do not silently reroute. The earlier four-call smoke test already established inference access. HF Pro has a small shared compute allowance under the [billing documentation](https://huggingface.co/docs/inference-providers/en/pricing); it is not unlimited GPU/training access or a transfer of Adaption credit.

Nominal limit **$1.00**, two simultaneous calls, 18,000 input-byte reservation and 4,096 output-token reservation per call. Before a two-call batch, reserve the upper estimated liability against the cumulative limit. This is not a provider-enforced monetary cap, and actual HF billing can post later.
