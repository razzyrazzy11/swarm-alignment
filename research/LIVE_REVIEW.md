# Pre-collection implementation review

6 November 2026. This log concerns the new live-audit-v1 implementation, not new empirical findings. Existing results-v1 remains unchanged. The app restart preserved source files and the hash-bound private design; no live inference had started and no uncertain request was retried.

OpenCode used isolated, allowlisted source copies without credentials, raw runs or private design facts. A four-file scout checked reusable adapters and highlighted usage accounting and imported-helper hashing. A separately generated reference implementation imports no engine helpers. Its initial 360 projection comparisons and a later 7,776 full/partial finite-world sweep agreed. The 13 engine tests passed, including all finite full-packet worlds, 2,688 projected main-grid fixture packets, same-instance inference, malformed records and metadata-only selection. An incorrect approval-join world-count expectation in the generated test was corrected; it was a fixture error, not an engine failure.

A two-file engine/reference security review found no concrete semantic mismatch within its read scope. Its namespace warning led to independently sampled private routes, aliases, approvals and record namespaces, committed by canonical hash before outputs. No hidden route can be regenerated from the public source-index number alone. The post-evaluation release discloses those contexts for replay; this is not a claim of permanent secrecy.

The runner/analysis review checked planned-call identities, no-retry continuation, bounded concurrency, conservative reservations, terminal failure retention, solo-history/delegated-context boundaries and source clustering. The latent unsupported HF-history case is now explicitly rejected. Qualification summaries and native-file hashes are retained in the completed release contract. Empty final answers are failed normalization; length-truncated HF answers remain incomplete even when final text is empty. Prior unsafe rows prevent continuation around a stop gate. These refinements occurred before registration/data.

Sixteen delegated runner tests and four independent root-authored analysis/replay tests pass. They cover request bodies, schemas, history boundaries, exposure controls, uncertain charges, authentication/gateway/incomplete gates, in-flight draining, exact-unstarted continuation, source denominators, host replay and metadata substitutions. Real-state fixtures can actually execute unauthorized fake writes; no policy enforcer makes violations impossible by construction. Test outputs are synthetic fixtures, not empirical observations.

These scoped automated checks do not independently validate every possible packet, guarantee provider uptime, constitute human author review or certify novelty. The prospective protocol, source hashes and tag fix the actual collection contract. The weight-space sidearm is separate and requires its own freeze before any corresponding model output.
